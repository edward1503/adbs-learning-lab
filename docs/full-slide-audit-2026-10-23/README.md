# Full-slide teaching audit · 2026-10-23

The v3.4.0 baseline mapped slide ranges but compressed many source examples, algorithms and proofs into short topic summaries. It did not meet the requirement that the notes teach the content visible in the slides. This revision expands all 27 EN/VI lectures in source order. It retains the plain reader style, existing lesson/section/quiz/lab links and separate supplementary resources.

## Scope and evidence

845 physical PDF pages map to 245 teaching units within the existing 117 sections. Each unit has original teaching prose and a source-page link; repeated animation states are explained as a sequence. The [machine-readable audit](coverage.json) records each page, destination, source SHA-256 and substantive requirements. Counts and links establish order and traceability; they do not by themselves establish semantic completeness. Source text was read across all 27 PDFs; numerical diagrams and progressive examples were checked against rendered source pages where extraction omitted their meaning.

The public PDFs are the reviewed source boundary. Restricted Learn worksheets, instructor-only data and external textbook chapters are not silently treated as supplied content. Historical administrative pages are identified as source context. Lecture 14 has four-up physical pages: the supplied PDF omits printed panels 11 and 13; these cannot be reconstructed from that file. Source simplifications/typos are qualified where needed (including L3 difference, L15 cost, L17 histogram labels, L24 K3 direction and L27 CAP). The website provides original explanatory text rather than reproducing the source slide images.

## Material additions

- L1–7: actual source datasets, SQL outputs and algebra intermediates; hardware derivations; pin/unpin and replacement traces; page layouts; compression encode/decode.
- L8–12: cost tables, tree split/redistribution/merge states, extendible-hash directory pointers, complete sort runs and duplicate-aware join examples.
- L13–18: iterator control flow, rewrite conditions and counterexamples, all source plan-cost ledgers, composite-key scan ranges, histogram frequencies/calculations, dynamic-programming passes and interesting orders.
- L19–22: concrete transaction schedules, conflict/view witnesses, locking and deadlocks, buffer-policy recovery, WAL ordering and every durable 2PC boundary/recovery case.
- L23–27: complete pattern matches, both containment-proof directions, minimisation, GYO and semijoin states, parallel redistribution scenarios, and precise NoSQL consistency/model trade-offs.
